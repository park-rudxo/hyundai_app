# 챙겨가 개발용 APK

휴대폰·차량·시연 APK는 **0.9.1(versionCode 14)**입니다. Pretendard 글꼴과 Material Symbols Rounded 아이콘을 앱 안에 포함했습니다. 제목·본문·버튼의 글자 규칙과 모서리를 통일했습니다. 폰은 밝은 회색 배경과 흰 카드, 파란 주요 버튼을 사용합니다. 지도 검색 화면도 같은 스타일을 적용하고 사진을 크게 보여줍니다. 차량은 중성색 다크 테마를 적용했습니다. [디자인 변경과 적용 범위](../docs/24-visual-design.md).

시작 로딩, 입력 중 자동 검색, 별명 저장, 단계별 준비 기능을 유지합니다.

- [휴대폰 APK](changyeoga-phone-debug.apk)
- [차량 APK](changyeoga-vehicle-debug.apk)
- [시연 APK](changyeoga-demo-debug.apk)
- [SHA-256](SHA256SUMS.txt)

장소 검색은 네트워크가 필요합니다. 백그라운드 도착 알림은 아직 구현되지 않았습니다. 기존 앱 위에 업데이트 설치하세요. 내부 사진·목록을 보존하려면 앱을 삭제하지 마세요.
