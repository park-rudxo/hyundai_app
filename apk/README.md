# 챙겨가 개발용 APK

휴대폰·차량·시연 앱 모두 **0.10.0 (versionCode 17)**입니다.

확정 C 디자인을 실제 앱에 적용했습니다. 따뜻한 밝은 배경, 얇은 구분선, Pretendard Regular, 채움 없는 블루 글자 버튼을 공통 사용합니다. 차량은 왼쪽 방문지와 오른쪽 준비물로 나눴습니다. 지도·공유 메모·캘린더·로딩·연결 창에도 같은 스타일을 적용했습니다.

- [휴대폰 설치](changyeoga-phone-debug.apk)
- [차량 설치](changyeoga-vehicle-debug.apk)
- [차량 화면 시연용](changyeoga-demo-debug.apk) — 일반 Android에서도 모의 P단 전환 가능
- [SHA-256](SHA256SUMS.txt)

기존 앱 위에 업데이트 설치하면 목록과 사진을 유지합니다. 장소 검색에는 네트워크가 필요합니다. 차량용은 실제 P단·UX 제한을 읽고, 시연용은 모의 입력을 사용합니다. 이 파일들은 debug 개발 빌드입니다.

구현 기능: 지도·장소 검색과 별명, 짐 사진 등록, 적재·전달 확인, Wi-Fi·ZIP 전송, 가스레인지 확인 기록, 텍스트 공유 수신, 최근 메모 보관과 Google 캘린더 일정 작성 연결. 반복 준비물과 백그라운드 자동 알림은 다음 개발 항목입니다.
