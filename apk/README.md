# 챙겨가 0.3.0 개발용 APK

2026-11-06 빌드. 아래 파일은 기능 확인을 위한 **debug APK**이며 공모전 제출용 release가 아닙니다.

| 파일 | 설치 대상과 용도 |
|---|---|
| [휴대폰용](changyeoga-phone-debug.apk) | Android 8 이상. 사진 촬영 미리보기·사진 선택·방문지/적재/전달 상태를 이 기기에 저장 |
| [차량용](changyeoga-vehicle-debug.apk) | Pleos/AAOS. 실제 P단과 UX 제한을 확인하며, 신호가 없으면 잠금 |
| [시연용](changyeoga-demo-debug.apk) | 개발 시연. 실제 차량 신호 대신 모의 P단 스위치 사용. 실차 사용 대상이 아님 |

설치 후 `예시로 둘러보기 → 실었어요 → 도착·전달 → 건넸어요`로 흐름을 확인할 수 있습니다. 친가를 선택하면 외가의 물건은 보이지 않습니다. 사진 등록은 방문지 선택 후 `사진 선택`을 이용합니다.

같은 네트워크에서 휴대폰의 사진·목록을 차량에 일회 전송할 수 있습니다. 주소·확인 문구·6자리 코드로 연결합니다. 실제 두 기기 Wi-Fi 시험은 아직이며 AVD 내부 전송 테스트를 통과했습니다. ZIP 내보내기/가져오기도 유지합니다. 자동 동기화는 아닙니다. 휴대폰 화면을 켜 둔 동안 GPS 도착 후보를 안내하며 확인형 음성 명령을 지원합니다. 차량 자동 도착·실시간 기기 간 동기화·예약 알림은 아직 없습니다. 실제 휴대폰 카메라 촬영과 양산차는 추가 검증이 필요합니다.
