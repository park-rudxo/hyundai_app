# 챙겨가 개발용 APK

휴대폰은 **0.8.1(versionCode 12)**입니다. 시작할 때 검색 서버를 깨우는 로딩 화면을 추가했습니다. 준비되면 자동 진입하며 실패 시 재시도하거나 준비 화면을 먼저 열 수 있습니다. 입력 중 자동 장소 검색과 큰 버튼 중심 UI를 유지합니다. 장소명·주소 목록에서 결과를 선택한 뒤 별명을 붙이거나 원래 장소명으로 저장합니다. PC나 USB 연결 없이 배포 서버를 사용합니다. 차량·시연 APK는 0.6.0을 유지합니다.

- [휴대폰 APK](changyeoga-phone-debug.apk)
- [차량 APK](changyeoga-vehicle-debug.apk)
- [시연 APK](changyeoga-demo-debug.apk)
- [SHA-256](SHA256SUMS.txt)

장소 검색은 네트워크가 필요합니다. 백그라운드 도착 알림은 아직 구현되지 않았습니다. 기존 앱 위에 업데이트 설치하세요. 내부 사진·목록을 보존하려면 앱을 삭제하지 마세요.
