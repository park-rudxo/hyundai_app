# 장소명 검색 앱 연결

2026-11-14 · 0.7.0 개발 코드

## 구현

앱 → 중계 서버 /places → NAVER API HUB 지역 검색. Secret은 서버에만 저장한다. PLACE_SEARCH_URL을 android/local.properties 또는 빌드 환경변수에 설정한다. HTTPS 배포 주소가 없으면 실사용 검색은 준비되지 않은 상태다. 기존 지도용 키와 검색용 키는 별개다.

검색은 장소명과 주소를 함께 표시하며 네이버 결과 순서를 유지한다. 결과를 선택하면 장소명·좌표를 지도에 반영하고 별명 없이 저장해도 장소명을 보존한다. 화면 회전과 기존 방문지 수정 시 이름도 유지한다. 서버 연결 오류와 결과 없음을 구분한다. 장소명이 아닌 지도 직접 선택은 기존 역주소 기능을 유지한다.

이전 UI 검토에 따라 현재 단계 중심으로 화면을 정리하고 반복되는 단계/추가 버튼을 줄였다. 차량 연결 기본 흐름을 유지하고 적재 취소·전달 취소 문구를 적용했다. 백그라운드 도착 알림은 이 변경에 포함하지 않았다.

## 검증

- 공식 API HUB 인증으로 수원월드컵경기장 결과 확인.
- 로컬 중계 HTTP 응답 5개, 경기장 본체 결과 포함 확인.
- 앱 및 계측 APK 빌드 통과.
- Android 35 실제 계측: PlaceSearchConnectionTest 1개 통과, 11.584초. 앱에서 실제 검색 요청 후 경기장 주소 결과를 선택하고 별명 대화상자를 확인했다.
- 첫 계측은 에뮬레이터 System UI 응답 경고가 포커스를 가로막아 실패했다. 경고 대기 처리 후 재실행해 통과했다.
- 테스트 APK는 localhost+adb reverse를 사용한다. 휴대폰 실사용 APK로 배포하지 않았고 apk 폴더의 기존 0.6.2 파일은 유지한다.

## 남은 연결 절차

호스팅 계정에서 Docker Web Service를 만들고 server 디렉터리를 배포한다. 키는 호스팅의 비공개 환경변수에 입력한다. HTTPS 주소를 전달받으면 PLACE_SEARCH_URL을 그 주소로 설정해 휴대폰 APK를 재빌드하고 실서버 연결 시험 후 배포한다.
