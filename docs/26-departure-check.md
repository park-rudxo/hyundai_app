# 출발 전 직접 확인 0.9.2

폰의 차에 싣기 단계에서 가스레인지를 직접 확인하고 시각을 저장한다. 선택적 체크이며 다음 단계 진행을 강제하지 않는다. 확인 취소 가능. SharedPreferences에 로컬 저장하고 새 외출 초기화 시 기록을 지운다. 차량 전송·자동 감지·사진·백그라운드 알림은 이번 기능에 포함하지 않는다.

검증: phone 빌드·단위 테스트 성공. Android 35에서 저장→새 Store 인스턴스 복원→초기화 테스트 1개 통과. 실제 UI에서 확인 버튼을 눌러 시각과 취소 표시를 확인했다. 기존 C 디자인 전체 적용은 별도 작업이다.
