# 가족 승용차에서 관찰할 새 출품 후보

2026년 11월 3일 · 참가자 결정으로 A(공유차 반납), B(방문 기사 메모), C(정차 중 가족 놀이)는 비교 대상에서 제외했다. 아래 아이디어는 검증 전 제안이다.

## 설명회 사진을 어떻게 반영했나

ZIP의 143556 화면은 모빌리티·라이프, 엔터테인먼트, 안전·동승자 케어 등을 예시로 든다. 143544 화면은 운전자·동승자가 원하는 경험에서 출발해 차량 상태·이동 맥락·하드웨어를 연결하는 흐름을 보여준다. 143131 화면의 평가 항목은 차량특화성·창의성·기술 활용성·사업성이다. 이번에는 가족 승용차에서 본인이 관찰 가능한 장면을 먼저 정하고, 기능 하나와 검증 질문 하나를 붙였다.

## 1. 장을 본 날, 트렁크에 둔 냉장품

**장면.** 마트에서 산 냉장품을 트렁크에 넣고 한두 곳 더 들른 뒤 귀가한다. 주차하고 내리는 순간까지 누가 장바구니를 챙길지 기억해야 한다.

**첫 시연.** 출발 전 동승자가 ‘이번 이동에 냉장품 있음’을 한 번 표시한다. 중간 정차에는 조용히 있고, 사용자가 지정한 마지막 정차에서 ‘트렁크 장바구니’를 표시한다. 물건을 자동으로 식별하는 기능은 가정하지 않는다. 시연은 마지막 정차를 수동 지정하고 실제 차량 신호와 시나리오 입력을 구별한다.

**사용자와 기술 검증.** 최근 실제로 잊었거나 가족이 서로 확인한 물건이 있었는가? 미리 표시하는 수고가 더 크면 후보를 접는다. 앞문 상태 조회는 성공했지만 트렁크 열림·주차 신호의 읽기 가능 여부와 순정 알림 중복은 별도 확인한다. 장보기 때 다시 쓰는지를 본다.

## 2. 가족 픽업, 서로 보이는 곳에서 만나기

**장면.** 아버지는 역 앞으로 오고 나는 출구 밖에 서 있다. 지도에서 둘 다 ‘역 앞’인데 진행 방향이 달라 서로 안 보인다. 전화를 걸어 건널지 돌아올지 다시 정하는 순간을 관찰한다.

**첫 시연.** 동승 예정자가 정차 가능한 약속 지점 두 곳 중 하나를 골라 출구 번호와 눈에 보이는 표지 하나를 보낸다. 출발 전 차 화면에서 목적지와 어느 쪽 도로인지 함께 확인한다. 도착 후 정차하면 ‘표지 앞에서 기다리는 중’이라는 최신 상태를 보여준다. 시연 데이터는 한 장소만 직접 답사해 만든다.

**사용자와 기술 검증.** 메신저 위치 공유나 내비 목적지 전송 뒤에도 설명 전화가 남는가? 기존 방법으로 충분하면 제외한다. 차량 측 안내 연동과 동승자 입력 전달을 나눠 시험한다. 비교 지표는 서로 만나기 전 위치 확인 연락 횟수다.

## 3. 터널을 지나고 나서도 들을 수 있는 오디오 한 문장

**장면.** 가족과 팟캐스트나 오디오북을 듣는데, 길 안내나 차 안 대화가 겹쳐 결말 한 문장을 놓친다. 조수석에서 몇 초 전인지 짐작해 여러 번 되감는 순간에 주목한다.

**첫 시연.** 자체 재생한 짧은 오디오에 안내가 겹치면 직전 문장 위치를 기억한다. 안내가 끝난 뒤 동승자가 ‘놓친 문장 듣기’를 한 번 눌러 이어 듣는다. 개인 개발 범위는 문장 시작 시각을 붙인 자체 음원 하나다.

**사용자와 기술 검증.** 순정 미디어의 일시정지·되감기로 이미 충분한지 먼저 비교한다. 가상 차량에서 실제 오디오 포커스 변경을 받을 수 있는지 시험한다. 모의 안내로만 동작하면 그렇게 표시한다. 다른 스트리밍 앱의 재생 제어 권한은 전제하지 않는다. 지표는 놓친 문장을 찾는 조작 횟수다.

## 다음 동승에서 확인할 것

주차한 뒤 ‘오늘 내가 아빠 대신 기억한 것, 설명한 것, 다시 조작한 것은 무엇이었나?’를 적는다. 위 세 가지에 맞는 일이 없었으면 실제 있었던 다른 장면을 적는다. 지금은 우선순위와 최종 주제 모두 미정이다.
