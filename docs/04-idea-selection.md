# 어떤 문제를 먼저 확인할까?

2026년 11월 2일 · 개인 참가 · 1차 목표는 기획서, 핵심 기능 APK와 시연 영상이다. 아래 세 장은 읽고 고를 후보이며 아직 인터뷰 결과는 없다.

## A. 반납 주소까지 왔는데 입구가 보이지 않는다

**누구의 어떤 순간인가.** 처음 가는 공유차 반납 장소. 지도는 목적지 도착을 알렸지만 큰길에서는 지하 진입로와 지정 주차면을 구분하기 어렵다는 가설이다. 쏘카가 공개한 실제 절차는 약정 위치에 주차하고 모바일 앱에서 반납하는 것이다. 운전자가 입구에서 얼마나 자주 헤매는지는 따로 확인해야 한다.

**지금과 달라지는 점.** 비교 대상은 주소 길 안내와 휴대폰 반납 안내다. 차량이 입구에 접근할 때 어느 쪽으로 진입하는지 한 문장으로 들려주고, 정차 후 지정 구역을 보여준다. 첫 시연은 직접 답사한 장소 한 곳으로 제한한다.

**30초 시연.** 0~10초에 테스트 좌표가 입구에 접근한다. 10~20초에 진입 방향이 음성으로 나온다. 20~30초에 차량을 세우고 지정 구역을 확인한다. 지하 GPS로 주차면을 판별한다는 가정은 두지 않는다.

**첫 확인.** 초행 이용자에게 지난 반납 때 다시 찾아본 화면을 물어본다. 위치 이벤트를 에뮬레이터에서 재현할 수 있는지 시험한다. 비교 지표는 진입로 오진입 횟수다. [1, 4]

## B. 지난번에 찾은 출입구를 다음 방문에도 기억하고 싶다

**누구의 어떤 순간인가.** 같은 건물에 재방문하는 설치·점검 기사. 주소는 알지만 작업자 출입구나 하역 위치를 다시 찾는다는 가설이다. 업무용 지도와 화물차 전용 내비는 이미 판매되고 있다.

**지금과 달라지는 점.** 기사에게 휴대폰 메모·메신저·기억 중 실제로 어떤 방법을 쓰는지 묻는다. 차량에서는 정차 후 장소에 짧은 메모를 남기고 다음 접근 때 검색 없이 듣는다. 첫 버전에는 개인이 남긴 현장 메모 한 개만 쓴다.

**30초 시연.** 0~10초에 가상 현장에서 정차 후 “하역 입구는 건물 뒤편”을 저장한다. 10~20초에 다음 방문 경로를 재생한다. 20~30초에 입구 근처에서 해당 메모만 읽어 준다.

**첫 확인.** 기사가 같은 현장에 다시 가는 주기와 실제 메모 사례를 하나 듣는다. 저장 좌표에 다시 접근할 때 한 번만 재생되는지 시험한다. 비교 지표는 현장 정보를 찾는 데 걸린 시간이다. [2, 4]

## C. 정차 중에 시작하고 출발할 때 바로 끝내는 가족 놀이

**누구의 어떤 순간인가.** 충전이나 픽업을 기다리는 보호자와 아이. 언제 출발할지 모르는 짧은 대기에 긴 콘텐츠를 시작하기 어렵다는 가설이다. 차량용 게임 픽조이와 이동 경로 기반 이야기 ‘창밖동화’가 비교 사례다.

**지금과 달라지는 점.** 휴대폰 영상이나 기존 인카 게임과 비교한다. 한 문제씩 소리로 듣고 함께 답하는 놀이로 구성하며, 정차가 끝나면 게임을 멈춘다. 핵심은 새 콘텐츠의 양보다 출발 전후 행동이다.

**30초 시연.** 0~10초에 가상 차량을 주차 상태로 두고 놀이를 연다. 10~20초에 음성 문제 하나를 듣고 답한다. 20~30초에 주차 상태를 해제해 놀이 화면이 닫히는지 확인한다.

**첫 확인.** 보호자에게 최근 대기 시간과 출발 때 하던 행동을 묻는다. SDK에서 주차 상태를 신뢰할 수 있게 구분할 수 있는지 먼저 시험한다. 상태를 모르면 게임을 시작하지 않는다. 비교 지표는 출발 준비 시 콘텐츠를 닫기 위해 필요한 조작 횟수다. [3, 4]

## 선택 기록

**기술 제약도 선택 기준이다.** 공식 신청 안내는 Vehicle State·NaviHelper를 신청 없이 사용 가능한 항목으로, FusedLocation·음성 입출력·Vehicle Control은 준비 중으로 표시한다. A·B의 위치와 음성은 해당 Pleos SDK를 쓸 수 있다고 가정하지 않는다. 두 후보에 포함되면 Android 위치·음성 API의 전용 AVD 지원 여부를 먼저 시험하고, 시연용 재생 좌표나 녹음 음성은 별도로 표시한다. C는 정차 판정에 쓸 읽기 신호의 지원 여부를 확인한다. [5]

| 단계 | 현재 기록 | 판단 근거 |
|---|---|---|
| 개인 경험 후보 D·E | 추가 입력 대기 | 최근 이동 한 장면, 지금 쓰는 해결법, 다시 겪는 빈도 |
| 먼저 볼 두 후보 | 참가자가 문서를 읽은 뒤 선택 | 이번 주에 당사자를 만나거나 직접 관찰할 수 있는가 |
| 최종 한 후보 | 미정 | 관찰한 불편, 차량에서 쓸 이유, 직접 작동을 확인한 기술 |

두 후보를 정하면 각각 “마지막으로 이 일을 한 때를 처음부터 이야기해 주세요”, “그때 다시 찾아본 정보는 무엇이었나요?”를 묻는다. 실제 사례와 팀 추측을 구분해 위 표에 기록한다.
