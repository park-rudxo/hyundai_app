# 현대자동차·경쟁사 앱 기능 지도

조사 기준: **2026년 11월 3일, 한국 시간.** 불편 사례 수집과 주제 선정은 중단하고 기존 기능 파악을 먼저 한다. 이번 범위는 현대자동차, Tesla, XPENG, NIO, Li Auto, BYD, Huawei, DiDi다. 완성차 회사뿐 아니라 차량 소프트웨어 공급사와 이동 서비스 플랫폼도 포함한다.

## 먼저 볼 직접 기능 목록 — 뉴스보다 우선

**조사 방식 정정:** 공식 기능 페이지·온라인 설명서 → 개발사 앱스토어 설명·스크린샷·버전 기록 순으로 확인한다. 아래 이전 조사에 인용한 뉴스룸·실적 발표는 발표 시점과 배포 여부를 보조 확인하는 데만 사용한다. 개인정보처리방침은 일반 이용자가 쓰는 기능 목록의 주 근거로 삼지 않는다.

아래 앱은 스토어에 표시된 개발사를 확인했다. 사용자 리뷰는 기능 근거에 포함하지 않았다. 중국 스토어 앱은 중국 내수 서비스이며 글로벌 앱과 구분한다. 스토어 소개문도 오래 남을 수 있어 최신 기능의 전체 목록이라고 단정하지 않는다.

## 읽는 기준

- **휴대폰 앱 / 차량 안 앱·음성비서 / 외부 서비스 연계**를 구분한다. 자동차에 있는 기능이 모두 휴대폰 앱 기능이거나 서드파티 개발자에게 열린 API라는 뜻은 아니다.
- **이용 안내**는 공식 지원 문서·설명서에 사용 절차가 있는 기능, **배포 발표**는 회사가 OTA 배포를 명시한 기능, **발표·계획**은 공개했으나 이 자료만으로 고객 제공 완료를 확인하지 못한 기능이다.
- 2026년 자료를 우선했다. 게시일 없는 현재 지원 페이지는 **11/3 열람·출시일 미표기**로 기록한다. 오늘 안내된다는 사실과 2026년에 처음 출시됐다는 주장은 다르다.
- 시장·차종·트림·하드웨어·구독·소프트웨어 버전에 따라 다르다. 해외 기능을 국내 지원으로 옮겨 적지 않는다. 공식 문서에서 못 찾은 기능은 ‘없음’이 아니라 **이번 조사 미확인**이다.
- 아래는 공식 자료 기반 1차 기능 목록이며 실차 전수 시험이나 전체 릴리스 이력은 아니다. 경쟁사의 하드웨어 연계 기능도 기존 제품 이해를 위해 기록하되, 이를 개인 개발 앱으로 재현할 수 있다고 가정하지 않는다.
