# Pleos 화면 구성 참고 디자인 · 0.9.0

공식 디자인 규격을 복제한 것이 아니라, 공식 공개 화면의 중성색 면·일관된 컴포넌트·명확한 정보 위계를 참고한 앱 디자인이다. 색상 수치는 이 프로젝트의 제안값이다.

## 적용

- 폰: #F5F6F8 배경, 흰 카드, #171B22 본문, #59616D 보조 글자, #315EE8 주요 행동.
- 차량: #111318 배경, #1D2128 카드, #A9BDFF 포인트. 기존 주차 제한 유지.
- 폰 제목 28sp, 주요 버튼 18sp/최소 60dp/모서리 16dp. 추가 방문지와 사진 추가는 보조 버튼으로 구분.
- 짐 사진은 폰에서 높이 180dp의 넓은 영역에 Fit으로 표시하여 잘림을 줄임. 차량 사진은 140dp.
- 적재 전체 진행 수를 표시하고 현재 방문지의 미적재 짐을 먼저 정렬.
- 지도 검색도 밝은 테마, 흰 결과 카드, 파란 저장 버튼. 장소명 굵게/주소 작게 표시.
- 키보드가 공백을 확정해도 같은 검색어를 재검색하거나 기존 선택을 해제하지 않음.
- 로딩·다이얼로그도 새 Material 테마를 공유.

## 기존 계획 중 이번 변경에 포함되지 않은 기능

차량 자동 발견·실제 가져오기 완료 추적·백그라운드 도착 안내·외출 기록 보관은 별도의 기능 구현이 필요하다. 이번 버전에서 완료됐다고 표시하지 않는다. 차량의 좌우 분할 레이아웃과 시스템 연동 주야간 테마도 후속 작업이다.

## 검증

폰·차량·시연 빌드 및 폰 단위 테스트 성공. 폰 에뮬레이터에서 검색/별명 1개와 로딩 3개 테스트 통과. 준비 흐름 테스트는 빠른 서버 응답 시 로딩 건너뛰기 버튼이 사라지는 타이밍을 처리한 뒤 6개 통과(57.688초). 차량 전용 테스트 함수는 폰에서 조기 반환하므로 차량 실기기 검증을 뜻하지 않는다. 이후 공통 모서리 수치만 조정하고 재빌드했다.
