# 텍스트 공유와 캘린더 연결 0.9.3

다른 앱에서 text/plain을 공유하면 확인 화면을 연다. 받은 글을 제목과 원문 필드에 표시하고 사용자가 수정·저장한다. 공유 내용은 최대 10000자, 최근 메모 1개를 로컬 보관한다. 새 공유를 저장하면 이전 메모가 교체된다. 화면 회전 시 입력을 복원한다.

방문지 화면의 Google 캘린더·공유 메모에서 다시 열 수 있다. 날짜/시간 선택, 제목·장소·메모 입력 후 Google 캘린더 앱의 일정 작성 화면을 우선 연다. 없으면 다른 캘린더 앱을 시도하고, 둘 다 없으면 설치 안내를 표시한다. 일정 길이는 기본 1시간이며 캘린더에서 변경 가능하다. 최종 저장은 캘린더에서 사용자가 수행한다.

캘린더 읽기/쓰기 권한이나 Google 계정 인증을 직접 요구하지 않는다. 기존 일정 가져오기·양방향 동기화·자연어 날짜/준비물 자동 추출은 미구현이다. 준비물 항목을 이름만으로 추가하는 기능은 요청에 따라 넣지 않았다. 공유 글은 별도 메모이며 현재 사진 짐 목록으로 자동 변환되지 않는다.

네트워크로 공유 원문을 전송하지 않는다. Google 캘린더로 보내기는 사용자가 버튼을 눌렀을 때만 일어난다. 이전 메모나 공유 내용을 차량으로 자동 전송하지 않는다.

검증: phone APK 빌드·단위 테스트 통과. 실제 ACTION_SEND 텍스트를 받아 제목/원문 표시, 저장 버튼 동작 확인. Google 캘린더 실행 확인. 에뮬레이터의 Google 캘린더는 첫 사용 안내 화면이라 최종 일정 저장과 계정 동기화는 검증하지 않았다.
