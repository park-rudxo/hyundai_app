# 시작 로딩 · 휴대폰 0.8.1

앱을 처음 열면 실제 검색 서버의 `/health`를 요청해 휴면 상태의 서버를 깨운다. HTTP 200과 JSON `ok: true`를 확인하면 자동으로 준비 화면을 연다. 검색 API 자체의 인증/응답 성공까지 보장하는 검사는 아니다.

- 고정 시간 지연이나 가짜 진행률을 넣지 않는다.
- 8초가 지나면 서버를 깨우느라 약 1분 걸릴 수 있다는 안내를 표시한다.
- 연결 제한 5초, 응답 읽기 제한 65초. 실패 시 ‘다시 시도’를 제공한다.
- 대기·실패 중에도 ‘준비 화면 먼저 열기’로 기존 목록과 사진 작업을 이용할 수 있다. 검색 서버를 건너뛴 경우 첫 검색은 지연될 수 있다.
- 지도에서 돌아오거나 화면을 회전할 때 완료한 로딩을 반복하지 않는다. 새 앱 실행에서는 다시 확인한다.
- 차량 APK에는 검색 서버 로딩을 적용하지 않는다. 백그라운드 유지 요청이나 유료 플랜 변경은 없다.

## 검증

APK 빌드 및 단위 테스트 성공. Android 35 에뮬레이터에서 준비 완료 전 대기, 완료 후 진입, 실패 후 재시도, 대기 중 건너뛰기를 세 가지 테스트로 확인했다(3개 통과, 10.122초). 실제 배포 서버로 앱을 새로 실행해 로딩 화면의 텍스트 및 버튼을 화면 계층에서 확인하고, 이후 방문지 준비 화면으로 자동 전환됨을 확인했다.
