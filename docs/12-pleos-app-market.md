# Pleos 앱마켓 — 공개 페이지와 확인한 앱 목록

2026.11.3 조사. **프로젝트의 우선 조사 대상은 Pleos다.** 불편 수집·주제 추천은 보류한다. 경쟁사 공식 기능 비교는 [11번 표](11-official-app-feature-map.md)를 참고한다.

## 마켓 페이지와 실제 목록의 차이

| 구분 | 공식 링크 | 확인 결과 |
|---|---|---|
| 제품 기능 | [Pleos Connect](https://pleos.ai/service-solution/pleos-connect/?locale=ko-KR) | Gleo·내비·앱 설치·OTA 소개 |
| 마켓 소개 | [Pleos App Market](https://pleos.ai/service-solution/pleos-app-market/?locale=ko-KR) | 개발·앱 생태계 안내. 이번 열람에서는 개별 앱 상세 페이지·전체 앱 카탈로그를 확인하지 못함 |
| 개발·유통 문서 | [Playground Connect 개요](https://document.pleos.ai/en/docs/connect/guide/connect) | 앱 개발·배포 구조. 소비자 앱 목록이 아님 |
| 실제 설치 화면 | 지원 차량의 Pleos Connect 앱마켓 | 공식 설명상 차량에서 앱 다운로드·이용. 이번에 실차 화면을 열람하지 않음 |
| 추가 사용자 설명 | [현대차 공식 화면 구성 매뉴얼](https://ownersmanual.hyundai.com/full_webhelp/CN8/2027/ko_KR/cluster-cluster_disp_info.html) | Pleos 화면 사용법. URL의 2027은 모델연도이며 게시일로 취급하지 않음 |

공개 웹 카탈로그가 존재하지 않는다고 확정한 것은 아니다. **현재 찾은 마켓 페이지는 소개 페이지이며 전체 앱 목록 확보는 미완료**다.

## 전체 개수와 남은 공백

공식 2026.9.9 자료는 신규 7종을 추가해 **총 18종**으로 확대했다고 밝혔다. 본문에서 이름을 명시한 신규 앱은 멜론·카카오내비이며 나머지는 라디오·오디오 카테고리로만 설명한다. 지원 차량으로 더 뉴 그랜저·디 올 뉴 아반떼 등을 기재한다. 이것은 **9월 발표 시점 수치**이지 11/3 실시간 앱 개수 보증이 아니다. [B]

| 아직 확인하지 못한 것 | 기록 원칙 |
|---|---|
| 18종 전체 앱 이름·개발사 | 알려진 음악·지도 앱 이름으로 빈칸을 추측해 채우지 않음 |
| 9월 이후 입점·삭제·업데이트 | 최신 공개 카탈로그·차량 화면·개발사 제품 문서로 추가 확인 필요 |
| 앱별 차량 버전·계정·구독·이용 가능 국가 | 휴대폰용 앱 기능과 동일하다고 가정하지 않음 |
| 개별 앱의 주행·정차 사용 제한 | 앱별 공식 이용 문서 확인 필요 |

## 출처와 조사 방식

일반 기능은 제품 페이지·온라인 설명서·개발사가 올린 스토어 설명을 우선한다. 이번 앱 개수는 마켓 소개 페이지에 없어서 **공급자 공식 발표만 보조 근거**로 사용했다. 일반 언론 기사·블로그·개인 SNS의 명단을 공식 목록으로 승격하지 않았다.

- **B** 현대차그룹·42dot, [2026.9.9 앱마켓 신규 7종 추가](https://www.hyundaimotorgroup.com/ko/news/42dot-pleos-connect-app-market-new-apps). 페이지 날짜는 9/9, 본문 발표 표현은 ‘7일 밝혔다’여서 구분해 보존한다.
