# 챙겨가 디자인 기준 C

2026-11-15 확정. 휴대폰·차량·시연 앱 0.10.0에 적용했습니다.

## 화면과 행동

따뜻한 밝은 배경 위에 글자와 얇은 구분선으로 내용을 나눕니다. 주요 행동은 채움·테두리 없이 글자와 화살표로 표시하고 하단 오른쪽에 배치합니다. 일반 행동도 같은 색과 굵기를 사용합니다. 터치 영역은 글자 폭보다 넓게 확보하되 넓은 색 면으로 표현하지 않습니다.

- 배경: #FAFAF8
- 본문: #30383E
- 보조 글자: #697278
- 행동: #426A92
- 구분선: #E5E7E7
- 오류: #A13E38

## 글자와 아이콘

Pretendard Regular 400을 제목·본문·버튼에 공통 적용합니다. 폰 제목 26/36sp, 항목 17/26sp, 본문 14/20sp, 버튼 15sp를 사용합니다. 차량 제목 30/40sp, 항목 24sp, 행동 20sp로 확대합니다. 시스템 글자 확대를 유지합니다.

Material Symbols Rounded 벡터를 사용합니다. 폰 24dp, 차량 32dp가 기본입니다. 진행 화살표는 같은 뒤로 아이콘을 회전해 사용합니다. 아이콘만 있는 동작에는 접근성 이름을 지정합니다.

## 배치

폰은 좌우 24dp, 한 번에 한 단계, 목록과 얇은 선, 하단 오른쪽 다음 행동을 기본으로 합니다. 차량은 좌우 32dp, 왼쪽 방문지와 오른쪽 준비물 목록으로 나눕니다. 내비게이션 동작은 차량 사이드 영역에 둡니다. 터치 높이는 폰 최소 48dp, 차량 64dp입니다.

사진은 작은 보조 썸네일로 표시하고 누르면 확대합니다. 사진이 없으면 빈 사진 상자 대신 준비물 아이콘을 표시합니다. 적재·전달 여부는 색상만으로 구별하지 않고 문구로 표시합니다.

지도 검색·별명·공유 메모·캘린더 작성·로딩·연결 팝업에도 같은 배경과 글꼴, 채움 없는 동작을 사용합니다. 외부 네이버 지도와 Google 캘린더 자체 화면은 각 서비스 UI를 따릅니다.
