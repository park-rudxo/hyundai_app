# 챙겨가 디자인 기준 v1

상태: 기준 확정안. 현재 APK 전체에 적용된 상태는 아니다.

## 방향과 우선순위

차분하고 정밀한 모빌리티 도구. 화면을 읽는 순서와 다음 행동이 분명해야 한다.

1. 글자·아이콘 일관성
2. 정렬·간격·버튼 위계
3. 선택·대기·성공·실패 상태
4. 폰/차량별 레이아웃
5. 짐 사진 표현(후순위). 사진 중심으로 전체 디자인을 결정하지 않는다.

플레오스 공개 UI의 단정한 영역 구분을 참고한다. 아래 값은 플레오스 공식 토큰이 아닌 이 앱의 기준이다.

## 글꼴

Pretendard 한 종류로 한글·영문·숫자를 통일한다. Regular 400, Medium 500, SemiBold 600만 기본 사용. 폰트 파일과 라이선스를 앱에 포함해 네트워크 없이 표시한다. 미지원 문자는 시스템 폴백. 차량 숫자/상태는 정렬과 판독성을 실제 화면에서 확인한다.

| 역할 | 폰 크기/행간(sp) | 굵기 |
|---|---|---|
| 화면 제목 | 26/34 | 600 |
| 구역 제목 | 20/28 | 600 |
| 항목명 | 17/24 | 600 |
| 본문 | 16/24 | 400 |
| 버튼 | 16/22 | 600 |
| 보조 설명 | 14/20 | 400 |
| 작은 상태 | 13/18 | 500 |

차량은 별도 스케일: 제목 30/40, 항목 24/32, 본문 20/28을 시작값으로 검증한다. 사용자 글자 확대를 제한하지 않고 레이아웃이 대응한다. 음수 자간은 기본 사용하지 않는다. 한국어 장문을 영문처럼 강제 줄바꿈하지 않는다.

## 아이콘

Google Material Symbols Rounded. 기본 FILL 0, weight 400, grade 0, optical size 24. 선택된 상태만 필요 시 FILL 1. 폰 24dp, 차량 32dp 시작값. 터치 영역은 폰 최소 48dp, 차량 최소 64dp를 프로젝트 기준으로 둔다. 차량용 최종 크기는 실제 Pleos 환경에서 검증한다.

앱에 쓰는 아이콘만 벡터로 포함한다. Material Icons와 Symbols, 이모지, 문자 화살표를 섞지 않는다. 뒤로 아이콘은 RTL 대응. 아이콘만 있는 버튼에는 접근성 이름을 제공한다. 익숙하지 않은 동작에는 글자를 함께 표시한다.

|---|---|
| 뒤로 | arrow_back |
| 닫기 | close |
| 추가 | add |
| 검색 | search |
| 장소 | location_on |
| 현재 위치 | my_location |
| 편집 | edit |

색만으로 의미를 전달하지 않고 아이콘과 글자를 함께 쓴다. 파랑=행동/선택, 초록=완료, 빨강=실패/삭제. 보조 글자와 비활성 버튼은 별도 역할이다. 배경/실제 글자 조합의 대비는 적용 시 검증한다.

## 간격과 형태

기본 간격 4/8/12/16/24/32dp. 폰 좌우 여백 20dp, 카드 내부 16dp, 같은 그룹 정보 4~8dp, 카드 사이 12dp, 구역 사이 24dp.

모서리: 입력창/버튼 12dp, 카드/시트 16dp, 배지 6dp. 원형은 아이콘 터치 영역/아바타 등 의미 있는 곳에만 사용. 기본 카드 그림자 없음. 경계선은 1dp. 모든 항목을 카드로 감싸지 않는다.

## 버튼과 상태

주요 행동은 화면당 한 개를 기준으로 Filled, 보조는 Tonal 또는 Text, 항목 편집은 Icon/Text로 표시. 폰 주요 버튼 최소 56dp, 차량 64dp 시작값. 고정 하단 버튼에 시스템 영역/키보드/큰 글자 대응.

대기 중에는 실제 진행 상태를 표시한다. 완료는 체크+설명, 실패는 원인+복구 행동. 성공하지 않은 작업을 완료로 표현하지 않는다. 삭제는 명확한 대상명을 보여준다. 모션은 의미 있는 상태 변화에 짧게 사용하고 시스템 모션 축소 설정을 존중한다.

## 사진(후순위)

사진은 물건을 식별하는 보조 정보다. 사진이 없어도 이름·방문지·상태·주요 행동의 위계가 유지돼야 한다. 큰 빈 사진 상자는 만들지 않는다. 사진 크기와 크롭 방식은 핵심 컴포넌트 적용 후 결정한다.

## 적용과 확인

공통 Theme/Typography/Icon 컴포넌트를 먼저 만든 뒤 준비 화면 → 검색/다이얼로그 → 차량 화면에 적용한다. 화면별 임의 색상/크기 지정은 피한다. 360dp 폰, 긴 장소명, 글자 확대, 차량 가로 화면, 밝음/어두움, 로딩/빈 상태/오류에서 확인한다.
